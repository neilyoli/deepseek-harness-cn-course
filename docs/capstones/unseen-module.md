# Capstone：陌生模块阅读测试

从 Skill、Subagent、Workflow、Goal、Schedule、Jobs、Plan、ACP、SDK、Web UI 里任选一个你没系统学过的。

## 限制

前 60 分钟不能看本站其他源码卡，只能用官方站点、Package README、Generated Reference、source、tests。

## 交付

1. owning subsystem；
2. package / contract；
3. provider / consumer；
4. lifecycle；
5. live / durable events；
6. 一条真实调用链；
7. 两个 failure / cancel / dispose case；
8. plugin extension point；
9. 如果要改一个行为，你会从哪里下手，以及为什么。

能完成这份报告，才说明你掌握的是研究方法，不是课程答案。
