## `StreamChunk` 是 closed protocol

【源码事实】当前 union：

```text
block-start
text-delta
reasoning-delta
tool-call-delta
block-end
usage
finish
```

契约：

- `usage` 必须在 `finish` 前；
- `finish` 后不能再 emit；
- tool-call arguments 全链路保持 raw JSON string；
- block index 第一次出现时分配，此后复用；
- adapter failure 可以 throw，或 terminal error/aborted finish；
- 必须 honor `options.signal`；
- 不支持的 request field 应显式 `UNSUPPORTED`，不能静默丢弃。

## Adapter 注册

【源码事实】官方 cookbook 的 canonical shape：

```ts
class MyAdapter extends LlmAdapter {
  async *stream(options: GenerateOptions): AsyncIterable<StreamChunk> {
    // translate provider protocol → StreamChunk
  }
}

export const inject = ['llm']

export function apply(ctx: Context) {
  ctx.llm.registerAdapter(['my-provider'], new MyAdapter(/* ... */))
}
```

registration 是 effect-based、HMR-safe；同 provider route duplicate 会 fail loud，多 route registration all-or-nothing。

## Lab 1：Deterministic Mock Adapter

【教学模型】实现 provider `course-mock`，固定输出：

```ts
async *stream(options: GenerateOptions): AsyncIterable<StreamChunk> {
  options.signal.throwIfAborted()
  yield { type: 'block-start', index: 0, blockType: 'text' }
  yield { type: 'text-delta', index: 0, text: 'hello ' }
  yield { type: 'text-delta', index: 0, text: 'harness' }
  yield { type: 'block-end', index: 0, block: { type: 'text', text: 'hello harness' } }
  yield { type: 'usage', usage: { inputTokens: 1, outputTokens: 2 } }
  yield { type: 'finish', reason: { kind: 'stop' } }
}
```

::: warning
上面的 `usage` / `finish` 字段细节必须以冻结 commit 的实际 TS 类型为准后再编译；本片段用于训练 chunk 顺序，不替代 source declaration。
:::

## Lab 2：非法 Stream

依次制造：

- finish 后再发 delta；
- block index 不一致；
- block-end 与 deltas 不匹配；
- tool arguments 不是合法 raw JSON 表达；
- 没 finish。

观察 `BlockAssembler` / runtime 的具体失败；从 tests 找 contract。

## Lab 3：`llm/stream` extension point

【源码事实】`llm/stream` 是 live waterfall。写 wrapper 记录：provider、model、开始/结束时间，但必须 preserve downstream iterator 和 signal semantics。

## Retry ownership

【源码事实】adapter 本身一调用就是一个 provider attempt；官方 contract 要求禁用 SDK/library 自己的隐式 retries。retry policy 位于 Harness higher layer，避免 adapter + Agent 双重重试。

## 验收

> 在不修改 `agent-loop` 的情况下接入一个 deterministic provider，支持 text + tool-call stream；能解释 assembler 为什么拒绝一个非法 stream；取消 Agent 时 adapter 能及时看到 signal。
