# Stage 0：环境、版本与真实运行

## 毕业能力映射

【教学模型】直接服务于：**源码阅读、插件排障、真实 composition 验证**。本章不过关，后面的所有“源码事实”都可能是在不同版本上讨论。

## 事实基线

【源码事实】当前要求 Node `^22.19.0 || >=24.0.0`，pnpm `11.7.0`。官方 source path 先 `pnpm install`，再 `pnpm run build`，最后 `pnpm dsh web`。

```bash
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
git checkout b150a551b8d465e31e418e1b2eaf5e79bbb7d28e
corepack enable
pnpm --version
node --version
pnpm install
pnpm run typecheck
pnpm run test
pnpm run build
```

【版本敏感】若这些命令与未来 README 冲突，重新冻结 commit，不要修教程来适应浮动 master。

## 仓库地图：只回答“去哪里找”

【源码事实】仓库顶层重点：

```text
apps/        CLI / Web 等应用 surface
packages/    DSH 各 capability / core / bundle / provider
vendor/      vendored Cordis/Cosmokit 等
examples/    示例入口
scripts/     catalogs / graphs / repo gates
website/     官方站点
.agents/     implemented/proposed/archived Agent Notes
```

【源码事实】`packages/README.md` 是 package group 总地图；不要从 `packages/` 逐目录扫起。

## 运行三种 surface

### Web

```bash
pnpm dsh web
```

【官方事实】默认本地 Web 地址是 `http://127.0.0.1:3080`。

### Headless

```bash
DEEPSEEK_API_KEY=... pnpm dsh --profile headless "summarize this workspace"
```

【源码事实】真实 API demo 需要 key；后续课程的多数架构 Lab 应优先使用 mock/replay，避免把 provider 网络波动混进 runtime 调试。

### Dump Profile

```bash
pnpm dsh --profile web --dump-default-config > /tmp/web.default.yml
pnpm dsh --profile web --dump-config > /tmp/web.effective.yml
```

## Lab：回答“我启动的到底是什么”

【教学模型】完成以下操作并保存输出：

1. `pnpm dsh --profile web --dump-default-config`。
2. `pnpm dsh --profile web --dump-config`。
3. 找出 `@deepseek-ai/dsh-base` 与 `@deepseek-ai/dsh-web-app` 的 layer boundary。
4. 随机选 5 个 row，记录 `id / name / inject / config / disabled`。
5. 对照 `packages/bundle/base/cordis.patch.yml` 与 `packages/bundle/web-app/cordis.patch.yml`，证明 dump 不是手写清单。
